# 🏠 דאשבורד נדל"ן — Ames Housing

דאשבורד אינטראקטיבי ב-Streamlit לניתוח 1,460 עסקאות נדל"ן מתוך מאגר Ames Housing (81 עמודות).

## הרצה

```bash
pip install -r requirements.txt
streamlit run app.py
```

הדאשבורד ייפתח בדפדפן בכתובת `http://localhost:8501`.

## מה יש בדאשבורד

### KPI
שישה מדדים ראשיים — מספר עסקאות, מחיר ממוצע, מחיר חציוני, מחיר ל-sq ft, שטח מגורים ממוצע וגיל ממוצע בעת המכירה. כל מדד מציג גם דלתא מול כלל הנתונים, כך שרואים מיד איך הפלח המסונן מתנהג ביחס לשוק. תחת "מדדים נוספים" יש שמונה מדדים משלימים (מחזור מכירות, מינימום/מקסימום, אחוז נכסים עם חניה/קמין ועוד).

### פילטרים (סרגל צד)
טווח מחיר, שכונה, שנת בנייה, איכות כללית, שטח מגורים — ובתפריט "פילטרים נוספים": סגנון בית, סוג מבנה, אזור תכנון, חדרי שינה, שנת מכירה, חניה, קמין, מיזוג מרכזי ותנאי מכירה. כפתור איפוס מחזיר הכל למצב ההתחלתי.

### גרפים (6 טאבים)
| טאב | תוכן |
|---|---|
| 📊 התפלגות | היסטוגרמת מחירים עם חציון וסקאלה לוגריתמית, התפלגות משתנה מספרי לבחירה, box plot ותרשים טבעת לפי קטגוריה |
| 📍 שכונות | דירוג שכונות לפי מדד נבחר עם מיון דו-כיווני, ו-violin plot של השכונות היקרות |
| 🧱 מאפייני הנכס | תרשים פיזור עם ציר X, צביעה וקו מגמה (OLS/LOWESS) לבחירה; מחיר לפי איכות; מפת חום חדרי שינה מול חדרי רחצה |
| 📈 מגמות בזמן | מגמת מחירים חודשית, נפח עסקאות, עונתיות לפי חודש ומחיר לפי עשור בנייה |
| 🔗 מתאמים | מטריצת מתאמים לבחירת משתנים ודירוג המשתנים המשפיעים ביותר על המחיר |
| 📋 טבלה | טבלה עם בחירת עמודות, מיון רב-עמודתי, הגבלת שורות, ייצוא CSV וסטטיסטיקה תיאורית |

### מיון
- דירוג השכונות: מהגבוה לנמוך, מהנמוך לגבוה או לפי שם.
- טבלת הנתונים: מיון לפי מספר עמודות יחד, בסדר עולה או יורד, או לחיצה ישירה על כותרת עמודה.

## שדות מחושבים
מעבר לעמודות המקוריות, האפליקציה מחשבת: `TotalSF` (שטח כולל), `PricePerSF` (מחיר ל-sq ft), `HouseAge`, `RemodAge`, `TotalBaths`, `Decade`, ודגלים לחניה/בריכה/קמין.
